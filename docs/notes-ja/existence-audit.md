# 「そもそも特異点解消は存在するのか」の監査

2026-09-06。問い：本プロジェクトが前提にしている「解消の存在」は、どこまでが確立していて、どこからが我々の導出か。

ラベル：`[F-AI]` 一次資料を本文で確認（ページ記載）／`[D]` 本プロジェクトの導出（未査読）／`[C]` 計算で確認／`[Q]` 未確認。

---

## 0. まず、混同してはいけない 2 つの主張

| | 主張 | 根拠の種類 |
|---|---|---|
| **E1** | **我々が計算した個々の例について、解消が存在する** | **構成的。定理に依存しない** |
| **E2** | 命題 M（A4 を満たす任意の quasi-homogeneous 錐について解消が存在する） | Bergh の定理に依存する |

**E1 と E2 は別物で、疑いの重さが全く違う。**

### E1 は自己証明的である

L2 が各サンプルについて実際に作っているのは、次の 3 つを満たす具体的な X̃ である。

1. **X̃ は滑らか**。滑らかなトーリック多様体 T の全チャートで、strict transform のヤコビ判定が単位イデアルを返す。ヤコビ判定は任意標数で有効 `[F-AI]`。
2. **X̃ → X は固有**。X̃ は T の閉部分スキームで、T → A^n は扇の細分が誘導する射。細分（同じ台）が誘導する射は固有 `[F-AI]`（Cox–Little–Schenck Thm 3.4.11）。台が一致することは今回コードで確認した `[C]`：全射線が閉正象限に入り、e_i がすべて射線として残り、正象限の内部の乱択点が必ずどれかの極大錐に入る（`checkRefinesOrthant`。E_8、4 次元 2 例、非 well-formed 例で 40/40）。
3. **X∖{v} 上で同型**。追加された射線がすべて正象限の**内部**にあるので、正象限の真の面はすべて残り、射は A^n∖{0} 上で同型 `[D]`（標準的なトーリック幾何）。

**つまり「x²+y²+z²+u²+v⁶ は char 3 で解消を持つか」という問いには、"はい、これがその解消です" と現物を出せる。** 定理を一切引用せずに。この意味で E1 は疑う余地がない。疑うとすれば実装のバグだが、それは C1（Artin の RDP 76 件）が古典分類の ADE と完全一致することで潰してある `[C]`。

## 1. E2（命題 M）の証明を段階ごとに監査する

設定：k 任意の体、R は k 上有限型の N-次数付き整域、R_0 = k、X = Spec R、v は頂点、**A4：X∖{v} は k 上滑らか**。

### S1. 𝒴 := [((X∖{v}) × A¹)/G_m] は k 上滑らかな代数スタック

G_m は t·(u,s) = (t·u, t^{-1}s) で作用（A¹ の重みは −1）。

- アトラス (X∖{v}) × A¹ は k 上滑らか `[D]`（A4 と A¹ の滑らかさ、積）。
- G_m は滑らかなアフィン群スキーム `[F-AI]`。
- 滑らかなスキームを滑らかな群スキームで割った商スタックは滑らか `[F-AI]`（アトラスが滑らか全射）。

**判定：確実。** ここは A4 だけから出る。

### S2. 安定化群は μ_r、inertia は有限

- s ≠ 0 の点では自明（t^{-1}s = s ⟹ t = 1）`[D]`。
- s = 0 の点 (u,0) では Stab = Stab_{G_m}(u) = μ_r、r = gcd{w_i : u_i ≠ 0} `[D]`。
- G_m の閉部分群スキームは G_m と μ_r のみ `[F-AI]`（対角化可能群 D(M) の閉部分群は D(M/N)、M = Z）。**任意の体で成立し、α_p は現れない。**
- inertia の有限性：x_i ≠ 0 の開集合上で安定化群は μ_{w_i} の閉部分群なので有限 `[D]`。

**判定：確実。** ここが「wild を踏まない」ことの正確な内容。

### S3. 𝒴 は tame で、安定化群は対角化可能

- μ_r は対角化可能 ⟹ linearly reductive `[F-AI]`（AOV Prop 2.10。p | r でも成立）。
- tame ＝ finite inertia ＋ linearly reductive stabilisers `[F-AI]`（Bergh p.5、AOV Def 3.1）。

**判定：確実。** p | r のとき 𝒴 は Deligne–Mumford でないが、tame ではある。

### S4. 𝒴 → X は固有で、X∖{v} 上で同型

- 射 (u,s) ↦ s·u = (s^{w_1}u_1,…,s^{w_n}u_n) は G_m-不変で、f が w-斉次なので像は X に入る `[D]`。
- s ≠ 0 の部分は X∖{v} と同型（s = 1 の切断が各軌道と一意に交わる）`[D]`。
- **固有性** `[D from F]`：𝒴 は [((A^n∖{0}) × A¹)/G_m] の閉部分スタック。後者の粗空間は古典的な重み付き blow-up（Bergh Def 3.3 の Cox 構成）で、その扇は正象限を細分し台が一致するので A^n 上固有 `[F-AI]`（CLS Thm 3.4.11）。有限 inertia を持つスタックが底上固有であることと粗空間が固有であることは同値 `[F-AI]`（Keel–Mori、Conrad）。

**判定：ほぼ確実だが、ここが一番薄い。** 個々の例では L2 が固有性を直接確認している `[C]`。

### S5. 粗空間 X′ は単体的トーリック商特異点しか持たない

- Bergh Thm A.1(e) `[F-AI]`（p.36 で確認）：X が tame・quasi-separated・S 上有限表示で**滑らか**なら、粗空間の étale 被覆上で X ≅ [U/G]、U は S 上滑らか、G は有限 linearly reductive。
- 我々の場合 G = μ_r は対角化可能 ⟹ X′ は étale 局所的に U/Δ（U 滑らか、Δ 有限対角化可能）`[D from F]`。
- これは Bergh の「simplicial toric singularities」の定義そのもの `[F-AI]`（p.3）。

**判定：確実。** ただし「p | w_i のとき素朴なスライスは特異になりうる」ことに注意 `[C]`（作業ログ（非公開））。étale 局所であることが本質で、Zariski 局所ではない。

### S6. Bergh Cor 1.3 を X′ に適用する

> **Corollary 1.3 (Functorial desingularisation of simplicial toric singularities).** Let X be an algebraic space of finite type over an arbitrary field k. Assume that X has simplicial toric singularities only. Then there exists a sequence Π: X_m → ⋯ → X_0 = X of proper birational modifications such that X_m is smooth. The construction is functorial with respect to change of base field and with respect to smooth maps X′ → X. `[F-AI]` p.3

- X′ が代数空間であること：Keel–Mori（有限 inertia）`[F-AI]`。
- X′ が k 上有限型：✓ `[D]`。
- 仮定「simplicial toric singularities only」：S5 ✓。
- **X∖{v} 上で何も起きないこと**：開埋め込み X∖{v} ↪ X′ は滑らかなので、関手性から X∖{v} 上への引き戻しは（滑らかな空間の解消列＝空列）と同値。よって中心は X∖{v} を避ける `[D from F]`。

**判定：確実。仮定はすべて満たされている。**

### 結論

**E2 の証明で、一次資料で確認できていない実質的な穴は無い。** 最も薄いのは S4 の固有性で、そこは古典的なトーリック幾何の事実（細分は固有射を誘導）に帰着し、個々の例では計算で直接確認した。

| 次元 | 一般の解消 | M の射程 |
|---|---|---|

**つまり M は「一般の解消が難しい理由」を回避しているのであって、それを解決してはいない。** レビュー文書 §8 の「言えないこと」の表がこれを述べている。

## 6. 追記：「大域的」な解消は得られているか

**問い**：このクラスの特異点について、局所的ではなく大域的な解消が得られているか。

### 6.1 文献の主張としては、得られている

Bergh Cor 1.3 は X 全体に対する主張である（「an algebraic space of finite type over an arbitrary field k … there exists a sequence Π: X_m → ⋯ → X_0 = X of proper birational modifications such that X_m is smooth」）`[F-AI]`。しかも関手的。Włodarczyk も同じく大域的に述べている `[F-AI]`（p.3「These can be resolved canonically by toroidal methods or by the destackification algorithm of Bergh and Rydh」）。

### 6.2 我々の計算では、大域的な解消は「ある」

**まず結論：大域的な解消は 329 件ある。** P1（トーリック埋め込み）は 1 つのトーリック多様体 T の中に閉部分スキーム X̃ を作り、全チャートで滑らかさを確認している。`certify.m2` はこれを 5 項目の証明書として出力する（A4 / T 滑らか / 固有 / 頂点外で同型 / X̃ 全チャート滑らか）。**解消定理を一切引用していない。**

無いのは「Bergh 経路で作った大域解消」と「標準的（関手的）な大域解消」であって、大域性そのものではない。

| | ある | 無い |
|---|---|---|
| 大域的な解消 | **ある**（P1、329 件 ＋ 次元 5・6 の 9 件） | — |
| 標準的な大域解消 | — | 無い（`makeSmooth` は任意選択、Bergh 経路は重複度 6 で停止せず） |
| Bergh 経路の大域解消 | — | 無い（局所モデルのみ） |

**そして標準性は本プロジェクトの目的のどれにも要らない。** 関手性が要るのは局所処方の貼り合わせだが、§6.5 のとおり層に沿って横断モデルが 1 種類しかないので貼り合わせは自明である。

### 6.2b 経路ごとの内訳

| 経路 | 大域的か | 実体 |
|---|---|---|
| **P1（トーリック埋め込み）** | **大域的** | 1 つのトーリック多様体 T の中に閉部分スキーム X̃ を構成し、全チャートで滑らかさを確認。**現物がある**（A4 を満たす 329 件） |
| **P2（Bergh 局所）** | **局所的** | 各層別点の局所モデル [A^m/μ_r] を解消しただけ。**大域的な X̃ は作っていない** |

**P2 が局所にとどまっているのは、本プロジェクトの正直な欠落である。**

### 6.3 局所から大域への貼り合わせが自動かどうかは次元による `[D]`

- **曲面（dim X = 2）：自動。** A4 のもとで X′ の特異点は Y = Proj R 上の**有限個の孤立点**なので、それぞれ独立に解消でき、台が交わらない。貼り合わせに条件が要らない。よって P2 も実質的に大域的。
- **dim X ≥ 3：自動でない。** 実データで正次元の層が出ている（`curvemu3_p3` は μ_3 が円錐曲線に沿い、`surfmu3_p3` は 2 次曲面に沿う）。このとき局所の処方が層に沿って整合する必要があり、それを保証するのが Bergh Thm 1.2 の関手性（smooth stabiliser-preserving 射に関する）。**我々はこの貼り合わせを計算で確かめていない。**

### 6.4 大域的**かつ標準的**なものだけが届かない `[C]`

外の重み付き blow-up は**大域的にトーリックスタック**なので、Algorithm B を直接当てれば大域的かつ関手的な細分が得られるはずである。実測したところ、極大錐の重複度で頭打ちになった。

| 重み w | 極大錐の最大重複度 | Algorithm B |
|---|---|---|
| (1,1,1) / (2,2,2,1) | 1 / 2 | 即座 |
| (2,2,3) / (1,2,3) / (3,3,2,1) | 3 | 即座 |
| (4,3,6)（E_6） | 6 | **180 秒で未完** |
| (6,4,9)（E_7） | 9 | **180 秒で未完** |
| (10,6,15)（E_8） | 15 | **180 秒で未完** |

一方 `makeSmooth`（アドホック）は E_8 でも 1 秒未満で終わる。

**結論：「大域的」と「標準的（関手的）」は現状どちらか一方しか取れない。**
- 大域的だが標準的でない → P1（`makeSmooth`）。現物はある。
- 標準的だが局所的 → P2（局所モデルへの Algorithm B）。
- 両方 → 重複度 3 までしか計算できない。

局所モデルの重複度は小さい（コーパスでは最大 5）ので P2 は動くが、外の空間の重複度は重み由来で大きくなる。**これは実装の効率の問題であって、理論の問題ではない。** 提案書の M6 が「本体」とされていた理由がここで実感される。

### 6.5 追記：層に沿った貼り合わせは確認できた `[C]`

`tests/stratum_constancy.m2` で、正次元の層に沿って局所モデルが一定であることを直接確かめた。

- **C1**：接空間の重み 0 の個数 = μ_r の固定軌跡の次元。全サンプルで一致。つまり局所モデルは（層の方向）×（横断的な商特異点）の積に分かれる。
- **C2**：層の上で generic に消えない偏微分が同時に消える「跳躍軌跡」は、頂点を除いて空。**A4 がこれを強制する**（そこは X の特異点になってしまう）。よって横断的なデータ (r, 重み) は層に沿って一定。
**訂正（2026-09-07）**：当初「各 X′ 上で横断モデルは 1 種類」と書いたが、これは 5 例からの過度な一般化だった。コーパス 135 件を走査した結果（`tests/monodromy_scan.m2`）：

| 族 | A4 成立 | 横断モデルが 2 種類以上 | 最大 | 跳躍軌跡あり | C1 失敗 |
|---|---|---|---|---|---|
| C1（RDP 76 件） | 76 | 28 | 3 | **0** | **0** |
| C5・C6・C10（72 件） | 59 | 10 | 4 | **0** | **0** |

E_8 は μ_2(1,1)・μ_3(1,2)・μ_5(1,4) の 3 種類を持つ。当然で、これが 3 本の腕に対応する。**異なる層が異なるモデルを持つのは正常**である。

**貼り合わせにとって重要なのは「1 つの層に沿ってモデルが一定か」であり、そちらは 135 件すべてで成立した**（跳躍軌跡 0、C1 失敗 0）。異なる層は互いに素なので、そこで整合条件は発生しない。

### 6.6 これを踏まえた次の一手

1. **Algorithm B の停止性**（重複度 6 以上）。キャッシュと重複度フィルタを入れても壁は動かず、原因は 1 ステップの費用ではなく blow-up の回数だと判明した。A2 の辞書式順序の読み方が効いており、既定値を変更して発散は収まったが未解決。`scripts/sweep_a2.sh` による A2 順序の総当たりを参照（作業ログは非公開）。

## 7. 接合部（seam）のリスク一覧

**問い**：引用している定理が各々正しくても、それらを**繋ぐところ**で間違えている可能性はどこにあるか。

証明書（P1、`certify.m2`）は**どの接合部にも依存しない**（定理を引用せず各主張を直接検証する）。以下は命題 M の一般証明にのみ効く。危険度の高い順。

### SEAM-1：𝒴 → X の固有性（S4）— **文献側は解決（2026-09-07）** `[F-AI]`

**Cox–Little–Schenck, *Toric Varieties*, Theorem 3.4.11 を本文で確認した。**

> **Theorem 3.4.11.** Let φ : X_Σ → X_{Σ′} be the toric morphism corresponding to a homomorphism
> φ : N → N′ that is compatible with fans Σ in N_R and Σ′ in N′_R. Then the following are
> equivalent: (a) φ is proper in the classical topology; (b) φ is a proper morphism;
> (c) …; **(d) φ_R^{-1}(\|Σ′\|) = \|Σ\|.**

さらに Example 3.4.12 が我々の場合をそのまま述べている：

> An important class of proper morphisms are the toric morphisms φ : X_{Σ′} → X_Σ **induced by a
> refinement Σ′ of Σ**. Condition (d) of Theorem 3.4.11 is obviously fulfilled since φ : N → N is
> the identity and every cone of Σ is a union of cones of Σ′.

Exercise 3.4.13 はこれを同値として述べる（「φ is proper if and only if Σ′ is a refinement of Σ」）。

**したがって「細分は固有射を誘導する」は `[F-AI]` になった。** 我々の `refinesOrthantExact` はまさに条件 (d) を有限の組合せで確かめている。

残るのは、[((A^n∖0)×A¹)/G_m] の粗空間が古典的な重み付き blow-up と一致するという識別（Cox 構成、Bergh Def 3.3）だけ。

- 扇の細分が固有射を誘導すること（Cox–Little–Schenck Thm 3.4.11）。**一次資料未確認。**

### SEAM-2：Bergh Cor 1.3 が「滑らかな軌跡の上で同型」を与えるか — **解決（2026-09-07）** `[F-AI]+[D]`

### SEAM-3：接空間の重みから局所モデルを読む計算 — **解決（2026-09-07）** `[F-AI]`

必要な連鎖は 3 段で、**3 段とも出典が付いた**。

1. **Bergh, Thm A.1(e)**：tame・S 上滑らかなスタックは、粗空間の étale 被覆上で [U/G]（U は S 上滑らか、G は有限 linearly reductive）。
2. **Bergh, Prop A.8**：「the point ξ lifts to a point ξ′ ∈ U which is fixed under the action of G」。つまり G-固定点が取れる。
3. **固定点での線形化**：Satriano, *The Chevalley–Shephard–Todd theorem for finite linearly
   reductive group schemes*, Algebra & Number Theory **6** (2012) 1–26 の
   **Corollary 1.8 の証明の第 1 段落**。原文（arXiv:0911.2058）：

   > Let V = m_x/m_x² be the cotangent space of x. As G is linearly reductive, there is a
   > G-equivariant section of m_x → V. This yields a G-equivariant map Sym•(V) → R, which
   > induces an isomorphism k[[V]] → Ô_{U,x} of G-representations. That is, complete
   > locally, we have linearized the G-action.

   仮定は「k は**任意の体**、U は k 上滑らかなアフィンスキーム、G は有限 linearly reductive
   群スキーム、x ∈ U(K) は G-固定点（K/k は有限分離拡大）」。**代数閉体も標数の条件も要らない。**
   μ_r は任意標数で有限かつ対角化可能、したがって linearly reductive なので、そのまま使える。

   立つのは「線形化は**完備局所**（Ô_{U,x} ≅ k[[V]]）」であって Zariski 局所ではない。
   我々の主張もその強さでしか述べていないので整合する。実際 p | w_i のとき素朴なスライス
   X ∩ {x_i = 1} は特異になりうる（E_8⁰ char 2 で確認済み）。

**代替出典**（同じ結論、仮定が強い）：

- Liedtke–Martin–Matsumoto, *Linearly reductive quotient singularities*, arXiv:2102.01067,
  **Proposition 6.4**：「G-作用が線形化可能 ⟺ G が linearly reductive」。ただし k は代数閉体で、
  作用は *very small*（閉点の外で自由）という仮定が付く。我々の設定では固定軌跡が正次元に
  なりうるので、この仮定は満たされないことがある。**Satriano を引くほうが正しい。**
- Alper–Hall–Rydh, arXiv:1504.06467, Ann. of Math. (2020) の étale スライス定理も同じことを
  与えるが、**代数閉体を仮定する**。Bergh A.1(e) は任意の底スキーム上なので、そちらが適切。

**SEAM-3 は閉じた。** 経験的な裏付けも別途ある（Artin の RDP 76 件が ADE と一致）。

#### 何がこれに乗っているか

### SEAM-4：層に沿った μ_r の同一視のモノドロミー — **解決（2026-09-07）** `[D]`

当初「Aut(μ_r) = (Z/r)^* のモノドロミーが局所処方を捻りうる」と懸念したが、**我々の設定ではモノドロミーは起こりえない**。理由は初等的である。

安定化群は**周囲の G_m の部分群スキームとして定まる**。点 u（非零座標の添字集合 K）に対し

  Stab(u) = { t ∈ G_m : t·u = u } = { t : t^{w_i} = 1 (i ∈ K) } = μ_{gcd(w_K)} ⊂ G_m。

これは K が同じ点すべてに対して **G_m の同一の部分群スキーム**である。局所的に選んだ同一視ではないので、選択の余地がなく、貼り合わせで捻れようがない。同様に接空間の μ_r-重みは w_j mod r という**固定された整数**で、点に依らない。

したがって層の上で inertia は μ_r × Z と標準的に同型であり、Aut(μ_r) への非自明なモノドロミーは存在しない。**SEAM-4 は閉じた。**

計算でも裏付けた：コーパス 135 件で跳躍軌跡 0 件、C1 失敗 0 件（`tests/monodromy_scan.m2`）。

### SEAM-5：Bergh Thm A.1(e) の G が対角化可能であること — **解決（2026-09-07）** `[D]`

SEAM-4 と同根であり、同じ議論で閉じる。A.1(e) の G は étale 近傍上の群スキームだが、我々の inertia は G_m の固定された部分群 μ_r から来るので**大域的に μ_r × Z**（Z は層）。よって étale 部分 Q は自明で、G は対角化可能に取れる。Bergh Cor 1.3 の「finite diagonalisable group Δ」の仮定を満たす。

なお剰余次数が 2 以上の層（例：D_4 char 3 の K={0,1} 成分）では層の点が Galois で入れ替わるが、入れ替わるのは**点であって安定化群ではない**。Bergh の定義は étale 近傍を許すので、そこで点を分離すればよい。

## 8. 古典的な意味での解消になっているか

**問い**：作った X̃ → X は、古典的な意味での特異点解消か。

### 古典的な要求と、我々の検証状況

| # | 古典的な要求 | 検証 |
|---|---|---|
| 1 | X̃ が正則（完全体上では滑らかと同値） | ✓ 証明書 (4)：全チャートでヤコビ判定 |
| 2 | π が固有 | ✓ 証明書 (2)：扇が正象限を細分 |
| 3 | π が双有理 | ✓ 下記の議論 |
| 4 | π が Sing(X) の外で同型 | ✓ 証明書 (3)：追加射線がすべて内部 |
| 5 | **例外集合が単純正規交叉（SNC）因子** | ✓ 証明書 (5)：**今回追加**。X̃ が全トーリック層と横断的 |
| 6 | π が**射影的** | ✓ 厳密有理数 LP で強凹な台関数を構成。下記 |

**したがって 1〜6 すべてを満たし、古典的な意味での解消になっている。**

### 3（双有理）が A4 から自動である理由 `[D]`

- **被約**：f が p 乗なら df ≡ 0 で A4 が落ちる。よって A4 ⟹ 被約。
- **既約**（n ≥ 3）：f が 2 つの因子に分かれると、2 成分の交わりは次元 ≥ dim X − 1 ≥ 1 になり、そこは特異点。A4（孤立）に反する。よって A4 ⟹ 既約。
- X̃ は strict transform、すなわち X∖{v} の閉包なので、π は X∖{v} 上で同型（証明書 (3)）かつ稠密像を持つ。よって双有理。

### 5（SNC）の検証方法と結果 `[C]`

滑らかなトーリック多様体 T のトーリック境界は SNC。したがって X̃ 上への制限が SNC 因子になるのは、**X̃ が T の各トーリック層と横断的に交わるとき**、ちょうどそのとき。チャートごとに、例外座標の任意の部分集合 S について ft|_{y_S = 0} が単元か滑らかな超曲面かを調べればよい。

**結果：E_8^0、E_6^0、3・4・5・6 次元、非 well-formed、正次元 μ_3 層の 8 例すべてで、非横断的な層 0、X̃ に含まれる層 0。** つまり例外集合は SNC 因子。

### 6（射影性）について `[D]`

Hironaka 型の古典的な定理は**射影的**な解消を与える。我々の π は固有だが射影性は未検証。

**射影的であるという議論**：出発点の重み付き blow-up は Rees 代数の Proj なので A^n 上射影的。`makeSmooth` はその後、格子点での星型細分（`toricBlowup`）を繰り返す。星型細分は軌道閉包に沿った blow-up で、係数イデアルの Proj なので射影的。`makeSmooth` のもう一方の分岐 `makeSimplicial` は非単体的な錐にしか作用せず、入力が単体的で星型細分が単体性を保つので呼ばれない（出力が滑らか ⟹ 単体的、で確認できる）。射影射の合成はアフィン底の上で射影的。**よって射影的なはずだが、この連鎖を検証していない。**

**検証した（2026-09-07）。** 上の議論に頼らず、**細分ごとに強凹な台関数を厳密な有理数線形計画で構成した**（`scripts/projectivity_exact.py`）。

定式化は次の通り。射線 v に高さ a_v を置き、各極大錐 σ の上で a を補間する線形形式 m_σ を取る。
細分が正則（＝射影的）であることは

  ⟨m_σ, v⟩ − a_v > 0   （すべての極大錐 σ と σ に属さないすべての射線 v）

と同値。a_v = p_v − m_v（p, m ≥ 0）と置き、t ≤ 1 のもとで t を最大化して
「(行) · a ≥ t」を課すと、**b ≥ 0 の標準形になるので原点が実行可能基底解**であり、
第 1 段階が要らない。**Bland の規則つきの厳密な有理数単体法**で解くので巡回もしない。
最適値が正なら射影的（a を 1/t 倍して証明書にする）、0 なら強凹な台関数は**存在しない**ので
本当に射影的でない。どちらにせよ「探索が失敗した」ではなく決着になる。

結果：
